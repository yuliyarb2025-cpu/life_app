# Game of Life — веб-приложение

Реализация игры «Жизнь» Конвея как веб-приложения на Vanilla HTML/CSS/JS
(без сборщика и внешних зависимостей).

## Команда агентов

- `orchestrator` (primary, default) — декомпозиция и координация.
- `analyst` (subagent) — требования и спецификация.
- `developer` (subagent) — реализация.
- `tester` (subagent) — тесты и проверка.

## Требования

- Поле: ширина 200, высота 100.
- Начальная позиция генерируется случайно.
- Правила эволюции: стандартные B3/S23 (рождение при 3 соседях, выживание при
  2–3, иначе смерть).
- Кнопки управления:
  - Старт — запуск автоматической эволюции.
  - Стоп — остановка.
  - Итерация вперёд — один шаг вперёд.
  - Итерация назад — один шаг назад (нужна история состояний).
  - Сгенерировать новую позицию — случайное перезаполнение поля.

## Структура (целевая)

```
index.html
styles.css
src/game.js       # чистое ядро: поле, правила, шаги, генерация
src/ui.js         # canvas, кнопки, таймер
tests/            # тесты без внешних зависимостей
```

## Запуск

Приложение использует ES-модули (`<script type="module">`), поэтому открывать
`index.html` напрямую по `file://` нельзя — браузер заблокирует загрузку
`src/ui.js` по CORS. Запускай локальный сервер:

```
python3 -m http.server
```

и открой http://localhost:8000

## Тесты

```
npm test        # node --test, без внешних зависимостей
```
